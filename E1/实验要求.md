# 智能决策综合实验一：基于WiFi多径信号的连续人体姿态智能评估

## 一、实验核心内容
本实验为时序高维多标签回归任务，目标是通过深度学习建立**WiFi信道状态信息（CSI）**到人体二维骨骼关键点的非线性映射，实现非接触式的人体姿态智能评估。
- **输入数据**：预处理后的WiFi CSI矩阵，单样本维度为 `540×20`
  - 空间维度540：1发2收拓扑下共18条空间天线链路，每条链路30个OFDM子载波的幅度值拼接得到
  - 时间维度20：对齐30FPS视觉标签时，单帧时长内同步采集的20个高频CSI数据包
- **输出目标**：15个人体核心骨骼关键点的二维坐标，单样本形状为 `15×2`
- **数据集规模**：5名受试者，8种连续动作，共500个CSI样本（总计36万帧）

## 二、实验要求
1. 了解WiFi无线感知的应用场景，明确非接触式姿态估计的技术优势与实验目的
2. 掌握基于深度学习的时序相关性、空间多径特征提取方法（如残差网络、TCN、注意力机制等）
3. 能够对连续时序回归问题进行定义与算法设计，理解PCK、MPJPE两类姿态评估指标
4. 具备Python+PyTorch环境下的深度学习编程、模型调优、参数量/FLOPs统计分析能力
5. 掌握**留一法（LOSO）**交叉验证策略，用于验证模型跨受试者的泛化能力
6. 实验过程记录详尽，代码结构清晰，结论准确，分析讨论深入

## 三、核心实验任务
1. **数据维度分析**：结合物理场景与公式，理解输入张量`540×20`的形成机制与物理含义
2. **网络模型设计**：构建深度回归网络，实现CSI数据到15个骨骼关键点的坐标映射
   - 基线方案：基于非对称卷积残差网络，空间轴下采样、时间轴保留特征
   - 可拓展方案：探索LSTM、Transformer、通道注意力等模块优化效果
   - 损失函数：推荐使用**Smooth L1 Loss（Huber Loss）**，提升离群噪声鲁棒性
3. **两种划分方式训练测试**
   - **Setting 1（随机划分）**：全量数据随机打乱，按比例划分训练集与测试集
   - **Setting 2（LOSO跨受试者划分）**：指定Subject 3为完全隔离的测试集，其余受试者数据按9:1划分为训练/验证集，验证模型泛化能力
4. **模型效果评估**
   - 精度指标：统计并报告 `PCK@0.2`、`PCK@0.5`、`MPJPE` 三项结果
   - 效率指标：使用工具统计模型参数量（单位M）与浮点运算次数FLOPs（单位B）
5. **结果可视化与误差分析**
   - 生成真实姿态与预测姿态的对比视频
   - 统计不同身体部位的误差，分析躯干、四肢等部位的误差差异及原因

## 四、交付物要求
### 1. 代码工程交付
文件组织需遵循以下结构：
- `model/` 文件夹：存储训练完成的模型权重文件
- `src/` 文件夹：存放所有源代码文件
- 入口文件：根目录下提供 `run.py` 或 `main.py`，可直接在命令行执行推理测试
- 推理输出：根目录下生成 `test_predictions.csv`，包含所有帧的真实坐标与预测坐标，字段需包含`sample_id`、`true_kpN_x`、`true_kpN_y`、`pred_kpN_x`、`pred_kpN_y`（N为0-14的关键点序号）
- 辅助输出：`keypoint_error_stats.csv`（各关键点误差统计）、`comparison_poses.mp4`（姿态对比视频）

### 2. 实验报告交付（必含内容）
1. 预处理特征分析与维度理解：结合物理场景与公式，解释输入张量`540×20`的来源与含义
2. 网络模型设计思路：阐述输入数据处理逻辑、关键点回归方案与网络结构的设计理由
3. 网络拓扑图说明：绘制所用神经网络架构图，并解释各层作用与维度变化
4. 两种划分方式的效果对比：完整报告Setting 1和Setting 2的各项评估指标结果
5. 结果可视化与误差分析：展示连续动作的姿态追踪截图，分析不同身体部位的误差差异及成因
6. 组员任务分工、实验心得体会

### 3. 禁止行为
- 禁止在Setting 2中将测试集受试者的数据混入训练集
- 禁止人工修改、伪造评测结果数据
- 禁止实验结果造假与报告抄袭
