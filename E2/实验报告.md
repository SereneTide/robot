# 二、实验原理与基础理论
## 2.1 七自由度KUKA IIWA机械臂结构与运动控制原理
KUKA IIWA是一款七自由度冗余机械臂，每个关节由独立的位置控制模式驱动，通过setJointMotorControl2设定各关节目标角度，并基于关节实际角度与目标角度之差是否小于容差阈值（JOINT_TOLERANCE=0.01rad）来判断是否到达目标。在笛卡尔空间运动控制中，首先调用calculateInverseKinematics进行逆运动学求解，将末端目标位姿转换为七维关节角度，再通过Cartesian线性插值将单次大位移分解为多步微小位移，每步分别求解逆运动学并驱动关节，以实现轨迹平滑。机械臂的抓取动作流程标准化为：水平移动至物块正上方安全高度→垂直下落至抓取高度→抬升回安全高度，以重复循环完成多物块遍历。
## 2.2 PyBullet仿真平台基础原理
PyBullet是一个基于物理引擎的机器人仿真库，支持刚体动力学、碰撞检测和运动学求解。本实验通过p.connect(GUI/DIRECT)初始化仿真客户端，GUI模式下可交互观察机械臂运动，DIRECT模式用于批量测试。场景构建通过加载URDF/SDF模型完成，包括地面plane.urdf、货架kiva_shelf及自定义彩色立方体物块。仿真推进通过p.stepSimulation()逐帧执行，配合p.getKeyboardEvents()监听键盘事件，实现Z键触发抓取流水线、A/R键触发避障路径执行等交互功能。
## 2.3 机械臂路径规划两类问题基础理论
本实验涉及两类路径规划问题。其一是TSP最短遍历路径规划：给定所有物料抓取点坐标，计算任意两点间的欧氏距离构建邻接矩阵，形成带权完全图，目标是寻找一条遍历所有节点且总距离最短的闭合路径。其二是网格地图避障路径规划：将物料三维坐标降维为二维平面障碍物，按网格分辨率生成二值网格地图（0为通路、1为障碍物），规划从起点到终点的无碰撞路径，要求避开所有物料占据的网格单元。两类问题分别对应多目标分拣的顺序优化和单目标运动的避障需求。
## 2.4 实验所用算法基础原理
本实验覆盖五种算法。贪心算法以指定起点出发，每步遍历所有未访问节点，选择距离当前点最近者加入路径，直至所有节点遍历完毕。模拟退火算法从随机初始路径开始，通过随机交换两个节点的位置生成邻域新解，以Metropolis概率准则exp(-ΔE/T)接受劣解，并按指数降温系数逐步降低温度，从而跳出局部最优。遗传算法模拟生物进化过程，以节点序列为个体，通过锦标赛选择、有序交叉（OX）和交换变异算子迭代进化种群，结合精英保留策略确保最优个体不丢失。A*算法在网格图上采用优先队列管理OpenSet和CloseSet，以曼哈顿或欧氏距离为启发函数，沿四邻域方向扩展节点，通过父节点回溯生成最短路径。RRT算法在连续空间内随机采样生成节点，以目标偏向概率提高采样效率，通过最近邻搜索扩展随机树，结合线段碰撞检测确保路径安全，迭代直至到达目标区域后回溯生成完整路径。

### 3.1.2 机械臂运动控制接口实现
机械臂控制封装在 SimRobot 类中，基于 PyBullet 的位置控制模式驱动各关节运动。核心接口分为三个层次：
底层关节控制 ：通过 setJointMotorControl2 设置各关节的目标角度、最大驱动力（300N）和最大速度（2.0 rad/s），以 _set_joint_positions() 统一驱动 7 个关节，并以各关节实际角度与目标角度偏差均小于 0.01 rad 作为到位判定条件。
笛卡尔空间运动 ： move_one_point(x, y, z, steps, orn) 实现了从当前末端位置到目标位置的平滑运动。其工作原理为：获取当前末端位姿后，在起点与终点之间执行线性插值，生成 MOVE_STEPS=120 个中间路径点；对每个插值点调用 PyBullet 的 calculateInverseKinematics 求解逆运动学，将笛卡尔坐标映射为 7 个关节角度；随后逐点驱动关节并推进 SIM_STEPS_PER_CMD=12 步仿真，使机械臂沿规划路径连续运动。运动完成后验证末端位置偏差是否小于 POSITION_TOLERANCE=0.015m 。
预设位姿 ： go_to_rest() 使机械臂回到待机安全位，关节角为 [0.0, 0.6, 0.0, -1.2, 0.0, 1.0, 0.0] ，末端位于 SAFE_Z=0.85m 的安全高度，为后续抓取动作做好准备。

核心代码如下：
```python
    def move_one_point(self, x: float, y: float, z: float,
                       steps: int = None, orn: tuple = None,
                       log: bool = True) -> tuple:
        """
        机械臂末端平滑移动至单个空间坐标，采用线性插值->IK求解->逐点位置控制。

        参数:
            x, y, z: 目标末端世界坐标
            steps: 插值步数 (默认MOVE_STEPS)
            orn: 目标末端姿态四元数
            log: 是否打印日志
        返回: (success, trajectory)
        """
        if steps is None:
            steps = MOVE_STEPS

        start_pos = self.get_end_effector_pos()
        start = np.array(start_pos)
        target = np.array([x, y, z])

        if log:
            print("[机械臂] move_one_point: (% .3f, % .3f, % .3f) -> (% .3f, % .3f, % .3f), 步数=%d" %
                  (start[0], start[1], start[2], target[0], target[1], target[2], steps))

        trajectory = []
        for i in range(1, steps + 1):
            alpha = i / float(steps)
            interp = start + alpha * (target - start)
            trajectory.append(tuple(interp))

            joint_angles = p.calculateInverseKinematics(
                self.robot_id,
                self.ee_link_index,
                targetPosition=interp.tolist(),
                physicsClientId=self.client_id,
            )

            self._set_joint_positions(list(joint_angles))
            for _ in range(SIM_STEPS_PER_CMD):
                p.stepSimulation(physicsClientId=self.client_id)

        final_pos = self.get_end_effector_pos()
        error = np.linalg.norm(np.array(final_pos) - target)
        success = error < POSITION_TOLERANCE

        if log:
            status = "[OK]" if success else "[WARN]偏差过大"
            print("[机械臂] %s -> 最终位置(% .3f, % .3f, % .3f), 误差=% .4f m" %
                  (status, final_pos[0], final_pos[1], final_pos[2], error))

        return (success, trajectory)
```

### 3.1.3 抓取动作流程设计
抓取流水线由 PickAndPlacePipeline 类封装，对每个物块执行标准化的"三段式"抓取动作循环：
1. 水平接近 ：末端执行器在 SAFE_Z=0.85m 安全高度上水平移动至物块正上方。首个物块从待机位直接执行水平接近，后续物块则从上一步抬升位水平转移至下一目标点。
2. 垂直下落 ：末端从安全高度沿Z轴垂直下落至 物块顶面z + GRASP_OFFSET_Z(0.03m) ，即到达物块上方3cm 处，模拟夹爪闭合前的定位。
3. 垂直抬升 ：抓取完成后末端垂直抬升回SAFE_Z=0.85m 的安全高度，准备进入下一物块的运动。
该流程对 5 个物块依次执行，采用"接近→下落→抬升"的标准化动作模板，保证了运动的可重复性和轨迹的一致性。各阶段运动均通过 move_one_point 的笛卡尔插值实现平滑过渡，而非直接跳变。

核心代码如下：
```python
    def run(self):
        """
        执行完整抓取流水线：
        对每个物块依次执行水平接近 -> 垂直下落 -> 垂直上升，物块间水平平移过渡。
        """
        print("\n[流水线] 启动: 物块数=%d, 安全高度=%.3f m, 抓取偏移=%.3f m\n" %
              (CUBE_NUM, SAFE_Z, GRASP_OFFSET_Z))

        print("[流水线] 机械臂回归待机位...")
        self.robot.go_to_rest(wait=True)

        for i, cube_pos in enumerate(self.cube_positions):
            cx, cy, cz = cube_pos
            safe_pos = (cx, cy, SAFE_Z)
            grasp_pos = (cx, cy, cz + GRASP_OFFSET_Z)

            print("\n[物块 %d/%d] 目标坐标: (%.3f, %.3f, %.3f)" %
                  (i + 1, CUBE_NUM, cx, cy, cz))
            if i == 0:
                phase_name = 'horizontal_approach'
            else:
                phase_name = 'horizontal_transfer'

            start_ee = self.robot.get_end_effector_pos()
            print("[流水线] 阶段%s -> 移动到物块#%d正上方 (%.3f, %.3f, %.3f)" %
                  (phase_name, i + 1, cx, cy, SAFE_Z))
            self.logger.log_phase(
                block_id=i, phase=phase_name,
                start_pos=start_ee, end_pos=safe_pos,
                start_ee=start_ee,
            )

            self.robot.move_one_point(cx, cy, SAFE_Z, log=False)
            end_ee = self.robot.get_end_effector_pos()
            self.logger.complete_last(end_ee)
            start_ee = self.robot.get_end_effector_pos()
            print("[流水线] 阶段vertical_descend -> 下落至物块#%d上方 "
                  "(%.3f, %.3f, %.3f)" % (i + 1, cx, cy, cz + GRASP_OFFSET_Z))
            self.logger.log_phase(
                block_id=i, phase='vertical_descend',
                start_pos=start_ee, end_pos=grasp_pos,
                start_ee=start_ee,
            )
            self.robot.move_one_point(cx, cy, cz + GRASP_OFFSET_Z, log=False)
            end_ee = self.robot.get_end_effector_pos()
            self.logger.complete_last(end_ee)
            start_ee = self.robot.get_end_effector_pos()
            print("[流水线] 阶段vertical_ascend -> 抬升至安全高度 "
                  "(%.3f, %.3f, %.3f)" % (cx, cy, SAFE_Z))
            self.logger.log_phase(
                block_id=i, phase='vertical_ascend',
                start_pos=start_ee, end_pos=safe_pos,
                start_ee=start_ee,
            )
            self.robot.move_one_point(cx, cy, SAFE_Z, log=False)
            end_ee = self.robot.get_end_effector_pos()
            self.logger.complete_last(end_ee)
            current_ee = self.robot.get_end_effector_pos()
            print("[流水线] 物块#%d 完成, 当前末端坐标: (%.3f, %.3f, %.3f)" %
                  (i + 1, current_ee[0], current_ee[1], current_ee[2]))

        print("\n[流水线] 全部%d个物块遍历完成，回归待机位..." % CUBE_NUM)
        self.robot.go_to_rest(wait=True)
        self.logger.print_summary()
```

### 3.1.5 仿真运行与结果
运行方式 ：执行 main.py 启动仿真，通过键盘事件驱动抓取流水线。
启动后机械臂自动归位至待机位，等待触发指令。
按下 Z 键 触发抓取流水线，机械臂依次遍历 5 个物块执行"接近→下落→抬升"动作。
按 ESC 键 退出仿真，自动保存轨迹数据到 trajectory_data.json 。
运行结果 ：以 config.py 中 PYBULLET_GUI=True 启动 GUI 模式，可实时观察机械臂运动过程；设置为 False 则进入 DIRECT 无界面模式，适合批量测试。仿真结束后可在控制台查看各阶段的耗时统计，并通过轨迹 JSON 文件分析末端执行器的定位精度和运动平滑性。

```python
    @staticmethod
    def _euclidean_dist(p1, p2):
        return np.sqrt(sum((a - b) ** 2 for a, b in zip(p1, p2)))

    def _build_adjacency(self):
        """构建n×n邻接矩阵。"""
        mat = np.zeros((self.n, self.n))
        for i in range(self.n):
            for j in range(self.n):
                if i != j:
                    mat[i][j] = self._euclidean_dist(self.points[i], self.points[j])
        return mat

    def router_distance(self, route):
        """计算路径序列总长度。"""
        total = 0.0
        for k in range(len(route) - 1):
            total += self._euclidean_dist(
                self.points[route[k]], self.points[route[k + 1]])
        return total
```

### 3.2.2 贪心算法实现
贪心算法封装在 TSPGreedy 类（tsp_greedy.py）中，继承自 TSP 基类。算法以节点 0 为固定起点，维护一个已访问标记数组 visited[] ，每一步遍历所有未访问节点，选择与当前节点距离最近的节点加入路径尾部，并更新当前节点指针，直至所有 n 个节点遍历完毕。
具体流程：
1. 初始化 visited = [False]*n ， route = [start_idx] ， current = start_idx ；
2. 循环 n-1 次：遍历所有 j，若 visited[j]==False 且 adj_matrix[current][j] 最小，则将 j 加入路径并标记已访问；
3. 返回完整路径序列及其总距离。
贪心算法的优势在于求解速度快、时间复杂度 O(n²)，但其本质是局部最优策略，每一步只关注当前最优选择，无法保证全局最优解。对于本实验的 5 节点规模，贪心算法通常能给出较优解，但对于更复杂的排布可能会陷入局部最优。

核心代码如下：
```python
class TSPGreedy(TSP):
    """贪心策略：以指定节点为起点，每步取距离当前点最近的未访问节点。"""

    def solve(self, start_idx=0):
        """
        start_idx: 起始节点索引
        返回: (route, total_distance)
        """
        n = self.n
        visited = [False] * n
        route = [start_idx]
        visited[start_idx] = True
        current = start_idx

        for _ in range(n - 1):
            nearest, min_d = None, float('inf')
            for j in range(n):
                if not visited[j] and self.adj_matrix[current][j] < min_d:
                    min_d = self.adj_matrix[current][j]
                    nearest = j
            route.append(nearest)
            visited[nearest] = True
            current = nearest

        return route, self.router_distance(route)
```
### 3.2.3 模拟退火算法实现
模拟退火算法封装在 TSPSA 类（tsp_sa.py）中，继承自 TSP 基类。算法从一条随机初始路径出发，通过反复"扰动→评价→接受/拒绝"的迭代过程，在搜索早期以较高概率接受劣解以逃离局部最优，随着温度降低逐渐收敛。
算法核心参数：初始温度 T_start=1000.0，终止温度 T_end=0.01，降温系数 alpha=0.98，最大迭代次数 max_iter=5000。
实现步骤：
1. 路径初始化 ：固定节点 0 为路径首节点，其余 n-1 个节点随机打乱顺序，生成初始路径；
2. 邻域扰动 ：每一轮迭代中，随机选择两个非起始节点（索引 i, j ∈ [1, n-1]），交换它们在路径中的位置，产生新路径；
3. Metropolis 接受准则 ：计算路径长度变化量 ΔE = new_dist - curr_dist。若 ΔE < 0（新路径更短），直接接受新路径；否则以概率 exp(-ΔE / T) 接受更差路径，允许算法跳出局部最优；
4. 降温 ：每轮迭代后执行 T = T × alpha，温度指数衰减；
5. 终止 ：当温度降至 T_end 以下或达到 max_iter 迭代次数时停止，返回历史最优路径。

核心代码如下：
```python
class TSPSA(TSP):
    """模拟退火：初始随机路径→交换扰动→Metropolis准则→降温迭代。"""

    def solve(self, start_idx=0, T_start=1000.0, T_end=0.01,
              alpha=0.98, max_iter=5000):
        """
        start_idx: 固定为路径首节点的索引
        返回: (route, total_distance)
        """
        others = [i for i in range(self.n) if i != start_idx]
        np.random.shuffle(others)
        curr_route = [start_idx] + others
        curr_dist = self.router_distance(curr_route)

        best_route, best_dist = curr_route[:], curr_dist
        T = T_start

        for _ in range(max_iter):
            i, j = np.random.randint(1, self.n, size=2)
            if i == j:
                continue
            new_route = curr_route[:]
            new_route[i], new_route[j] = new_route[j], new_route[i]
            new_dist = self.router_distance(new_route)

            delta = new_dist - curr_dist
            if delta < 0 or np.random.random() < np.exp(-delta / T):
                curr_route, curr_dist = new_route, new_dist
                if curr_dist < best_dist:
                    best_route, best_dist = curr_route[:], curr_dist

            T *= alpha
            if T < T_end:
                break

        return best_route, best_dist
```

### 3.2.4 遗传算法实现
遗传算法封装在 TSPGA 类（tsp_ga.py）中，继承自 TSP 基类。算法模拟生物进化过程，通过种群迭代、选择、交叉和变异操作，逐步优化路径质量。
算法核心参数：种群规模 pop_size=100，迭代代数 generations=500，变异率 mut_rate=0.15，精英保留比例 elite_rate=0.1。
实现步骤：
1. 种群初始化 ：生成 pop_size=100 条随机路径，每条路径以节点 0 固定为首位，其余节点随机排列；
2. 适应度评价 ：对每个个体计算路径总长度，适应度 f = 1 / distance，路径越短适应度越高；
3. 精英保留 ：每代按适应度排序，保留前 elite_rate（即 10 个）最优个体直接进入下一代，确保最优解不丢失；
4. 锦标赛选择 ：从当前种群中随机抽取 k=3 个个体，选择其中适应度最高者作为父代；
5. 有序交叉（OX） ：对两个父代个体 p1、p2，随机选取一段连续子序列从 p1 保留到子代，子代其余位置按 p2 中节点的相对顺序依次填充，跳过已使用的节点和固定起点；
6. 交换变异 ：对子代个体，以 mut_rate=0.15 的概率随机交换两个非起始节点的位置；
7. 终止 ：迭代 generations=500 代后，返回当代种群中最短路径及其距离。

核心代码如下：
```python
    def solve(self, pop_size=100, generations=500,
              mut_rate=0.15, elite_rate=0.1):
        """
        返回: (route, total_distance)
        """
        pop = self._init_pop(pop_size)

        for _ in range(generations):
            fitness = np.array([1.0 / self.router_distance(ind) for ind in pop])
            n_elite = max(1, int(pop_size * elite_rate))
            elite_idx = np.argsort(fitness)[-n_elite:]
            new_pop = [pop[i] for i in elite_idx]

            while len(new_pop) < pop_size:
                p1 = self._tournament(pop, fitness)
                p2 = self._tournament(pop, fitness)
                child = self._ox_crossover(p1, p2)
                if np.random.random() < mut_rate:
                    self._swap_mutate(child)
                new_pop.append(child)
            pop = new_pop

        best = min(pop, key=lambda r: self.router_distance(r))
        return best, self.router_distance(best)

    def _ox_crossover(self, p1, p2):
        """
        有序交叉(OX)：从p1截取子序列，其余按p2顺序填充，保持起始点不变。
        """
        n = len(p1)
        a, b = sorted(np.random.choice(range(1, n), 2, replace=False))
        child = [-1] * n
        child[a:b] = p1[a:b]
        used = set(child[a:b]) | {0}
        fill = [x for x in p2 if x not in used]
        idx = 0
        for i in range(1, n):
            if child[i] == -1:
                child[i] = fill[idx]
                idx += 1
        child[0] = 0
        return child

    def _swap_mutate(self, route):
        """交换变异：随机交换路径中两个非起始节点。"""
        i, j = np.random.randint(1, self.n, size=2)
        route[i], route[j] = route[j], route[i]
```

```python
class MapFromPoints:
    """
    二维网格地图：输入障碍物点集，生成二值网格 (0=通路, 1=障碍物)。
    提供世界坐标与网格UV坐标的双向转换、网格文本可视化。
    """

    def __init__(self, obstacle_points: list, resolution: float, margin: float,
                 half_extents: tuple):
        """根据障碍物点集创建二维二值网格地图。"""
        self.resolution = resolution
        self.half_extents = half_extents[:2]  # (hx, hy)

        obs_xy = np.array([(p[0], p[1]) for p in obstacle_points])

        self.x_min = obs_xy[:, 0].min() - margin
        self.x_max = obs_xy[:, 0].max() + margin
        self.y_min = obs_xy[:, 1].min() - margin
        self.y_max = obs_xy[:, 1].max() + margin

        self.cols = int(np.ceil((self.x_max - self.x_min) / resolution)) + 1
        self.rows = int(np.ceil((self.y_max - self.y_min) / resolution)) + 1

        self.grid = np.zeros((self.rows, self.cols), dtype=np.int8)
        self._mark_obstacles(obs_xy)

        print("[网格地图] 创建完成: %dx%d 网格, 分辨率=%.3fm, "
              "范围x[%.3f,%.3f] y[%.3f,%.3f]" %
              (self.rows, self.cols, resolution,
               self.x_min, self.x_max, self.y_min, self.y_max))

    def _mark_obstacles(self, obs_xy: np.ndarray):
        """将障碍物占据的网格单元标记为1。"""
        hx, hy = self.half_extents
        for ox, oy in obs_xy:
            u_min = max(0, self.world_to_grid_u(ox - hx))
            u_max = min(self.cols - 1, self.world_to_grid_u(ox + hx))
            v_min = max(0, self.world_to_grid_v(oy - hy))
            v_max = min(self.rows - 1, self.world_to_grid_v(oy + hy))
            for v in range(v_min, v_max + 1):
                for u in range(u_min, u_max + 1):
                    self.grid[v, u] = 1
        obstacle_count = np.sum(self.grid)
        print("[网格地图] 障碍物网格数: %d / %d (%.1f%%)" %
              (obstacle_count, self.grid.size,
               100.0 * obstacle_count / self.grid.size))
```
### 3.3.2 A*路径规划算法实现
A*算法封装在 astar_plan() 函数（path_astar.py）中，严格按照伪代码实现 OpenSet/CloseSet 双集合管理，采用优先队列（ heapq ）维护待扩展节点，确保每次取出 f 值最小的节点。
核心参数： 启发函数类型 ASTAR_HEURISTIC='euclidean' （采用欧氏距离），四邻域扩展（上、下、左、右），网格边权固定为 1。
算法步骤：
1. 起点终点检查 ：确认起点和终点所在网格均为自由通路，否则直接返回失败；
2. OpenSet 初始化 ：将起点加入优先队列，g(start)=0，f(start)=h(start)；
3. 主循环 ：弹出 OpenSet 中 f 值最小的节点 (u, v)：
a)	若 (u, v) 已在 CloseSet 或 g 值过期，跳过；
b)	若 (u, v) 为目标点，回溯父节点生成完整路径并返回；
c)	将 (u, v) 加入 CloseSet；
d)	遍历四邻域 (u+1,v)、(u-1,v)、(u,v+1)、(u,v-1)：
i.	跳过障碍物网格和已在 CloseSet 的节点；
ii.	计算新 g' = g + 1，若 g' 小于已知 g_cost，则更新父节点、g_cost 和 f = g' + h(u',v')，并将 (u',v') 推入 OpenSet；
4. 终止 ：若 OpenSet 为空仍未到达目标，返回规划失败。
A*算法的优势在于能够保证在网格图上找到最短路径（在欧氏距离启发下，当网格为八邻域时需使用八方向扩展以保证最优性，本实验采用四邻域扩展，路径为曼哈顿意义上的最短）。其时间复杂度与搜索空间大小相关，在网格规模较小时规划速度极快（毫秒级）。

核心代码如下：
```python
def astar_plan(grid_map, start_uv: tuple, goal_uv: tuple,
               heuristic: str = 'euclidean') -> tuple:
    """A*网格路径规划。返回 (grid_path, elapsed_time)。"""
    t0 = time.perf_counter()
    su, sv = start_uv
    gu, gv = goal_uv

    if not grid_map.is_free(su, sv):
        print("[A*] 起点 (%d,%d) 位于障碍物上，规划失败" % (su, sv))
        return None, time.perf_counter() - t0
    if not grid_map.is_free(gu, gv):
        print("[A*] 终点 (%d,%d) 位于障碍物上，规划失败" % (gu, gv))
        return None, time.perf_counter() - t0

    def _h(u, v):
        if heuristic == 'manhattan':
            return abs(u - gu) + abs(v - gv)
        else:
            return np.hypot(u - gu, v - gv)

    neighbors = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    open_heap = []
    g_cost = {start_uv: 0}
    parent = {start_uv: None}
    closed = set()

    heapq.heappush(open_heap, (_h(su, sv), 0, su, sv))

    while open_heap:
        f, g, cu, cv = heapq.heappop(open_heap)

        if (cu, cv) in closed:
            continue
        if g_cost.get((cu, cv), float('inf')) < g:
            continue

        if (cu, cv) == goal_uv:
            elapsed = time.perf_counter() - t0
            path = _reconstruct_path(parent, goal_uv)
            print("[A*] 规划成功, 路径长度=%d 节点, 耗时=%.4fs" %
                  (len(path), elapsed))
            return path, elapsed

        closed.add((cu, cv))

        for du, dv in neighbors:
            nu, nv = cu + du, cv + dv
            if not grid_map.is_free(nu, nv) or (nu, nv) in closed:
                continue
            ng = g + 1
            if ng < g_cost.get((nu, nv), float('inf')):
                g_cost[(nu, nv)] = ng
                parent[(nu, nv)] = (cu, cv)
                nf = ng + _h(nu, nv)
                heapq.heappush(open_heap, (nf, ng, nu, nv))

    elapsed = time.perf_counter() - t0
    print("[A*] 规划失败, OpenSet已空, 耗时=%.4fs" % elapsed)
    return None, elapsed
```
### 3.3.3 RRT路径规划算法实现
RRT（Rapidly-exploring Random Tree）算法封装在 rrt_plan() 函数（path_rrt.py）中，通过在连续空间内随机采样、逐步扩展随机树的方式探索路径。
核心参数： 扩展步长 RRT_STEP_SIZE=0.02m ，最大迭代次数 RRT_MAX_ITER=5000 ，目标到达阈值 RRT_GOAL_THRESHOLD=0.03m ，目标偏向采样概率 RRT_GOAL_BIAS=0.1 。
算法步骤：
1. 起点终点检查 ：确认起点和终点不在障碍物上，否则返回失败；
2. 树初始化 ：以起点坐标 [sx, sy] 为根节点，父指针为 -1；
3. 迭代扩展（最多 max_iter 轮） ：
a)	随机采样 ：以 goal_bias=0.1 的概率直接以目标点作为采样点，其余 90% 的概率在采样空间内均匀随机采样。目标偏向策略显著提高了树的收敛速度；
b)	最近邻搜索 ：遍历当前树中所有节点，找到距离采样点最近的节点 nearest；
c)	扩展新节点 ：从 nearest 沿采样点方向扩展步长 distance = min(step_size, dist)，生成新节点坐标；
d)	碰撞检测 ：调用 grid_map.is_line_collision() 检测从 nearest 到新节点的线段是否穿过任何障碍物网格，若穿过则丢弃该新节点；
e)	添加节点 ：碰撞检测通过后，将新节点加入树中，记录其父节点索引；
f)	到达判定 ：若新节点与目标点的距离 ≤ goal_threshold，则以目标点为终止节点，从目标点回溯父指针生成完整路径；
4. 终止 ：达到最大迭代次数仍未到达目标区域则返回规划失败。
RRT是一种基于随机采样的运动规划算法，不需要对空间进行显式建模，适用于高维空间和复杂约束环境。由于随机采样的性质，RRT每次规划结果的路径形状可能不同，且一般无法保证找到最短路径，但能以较高概率找到一条可行路径。

核心代码如下：
```python
def rrt_plan(grid_map, start_xy: tuple, goal_xy: tuple,
             step_size: float, max_iter: int,
             goal_threshold: float, goal_bias: float) -> tuple:
    """RRT路径规划。返回 (world_path, elapsed_time)。"""
    t0 = time.perf_counter()
    sx, sy = start_xy
    gx, gy = goal_xy

    su, sv = grid_map.world_to_grid(sx, sy)
    gu, gv = grid_map.world_to_grid(gx, gy)
    if grid_map.is_obstacle(su, sv):
        print("[RRT] 起点 (% .3f,% .3f) 位于障碍物上" % (sx, sy))
        return None, time.perf_counter() - t0
    if grid_map.is_obstacle(gu, gv):
        print("[RRT] 终点 (% .3f,% .3f) 位于障碍物上" % (gx, gy))
        return None, time.perf_counter() - t0

    x_range = (grid_map.x_min, grid_map.x_max)
    y_range = (grid_map.y_min, grid_map.y_max)

    nodes = [[sx, sy, -1]]

    for i in range(max_iter):
        if random.random() < goal_bias:
            rx, ry = gx, gy
        else:
            rx = random.uniform(*x_range)
            ry = random.uniform(*y_range)

        nearest_idx = _nearest(nodes, rx, ry)
        nx, ny = nodes[nearest_idx][0], nodes[nearest_idx][1]

        dx = rx - nx
        dy = ry - ny
        dist = np.hypot(dx, dy)
        if dist < 1e-9:
            continue
        ex = nx + (dx / dist) * min(step_size, dist)
        ey = ny + (dy / dist) * min(step_size, dist)

        if grid_map.is_line_collision(nx, ny, ex, ey):
            continue

        new_idx = len(nodes)
        nodes.append([ex, ey, nearest_idx])

        if np.hypot(ex - gx, ey - gy) <= goal_threshold:
            goal_idx = len(nodes)
            nodes.append([gx, gy, new_idx])
            path = _backtrack(nodes, goal_idx)
            elapsed = time.perf_counter() - t0
            print("[RRT] 规划成功, 路径长度=%d 节点, 迭代=%d, 耗时=%.4fs" %
                  (len(path), i + 1, elapsed))
            return path, elapsed

    elapsed = time.perf_counter() - t0
    print("[RRT] 规划失败, 达到最大迭代次数%d, 耗时=%.4fs" % (max_iter, elapsed))
    return None, elapsed
```

### 3.3.5 机械臂避障运动验证
路径规划完成后，主程序进入仿真循环，等待键盘触发。机械臂避障运动由 execute_path() 函数实现，支持 A* 和 RRT 两套路径的独立执行验证。
操作方式：
1)	按下 A 键 → 机械臂沿 A* 规划路径运动
2)	按下 R 键 → 机械臂沿 RRT 规划路径运动
3)	按下 ESC 键 → 退出仿真
运动流程（四阶段）：
1. 水平接近起点 ：机械臂从待机位（SAFE_Z=0.85m）水平移动至路径起点的正上方；
2. 垂直下降至执行高度 ：末端沿 Z 轴垂直下降至 PATH_Z=0.25m （物块顶面 0.05m 上方 20cm，确保机械臂末端在物块上方安全通过，同时保持工作台高度附近的可达性）；
3. 沿路径逐点运动 ：遍历路径世界坐标点列表，逐点调用 robot.move_one_point(wx, wy, PATH_Z) 驱动末端沿水平路径运动。每个目标点执行前进行 碰撞预检 ——检查该点 (x, y) 是否落入任何物块的半长宽范围内，若碰撞则记录碰撞计数并输出碰撞日志。运动后还检查末端是否成功到达目标（偏差 < POSITION_TOLERANCE），若不可达则记录不可达计数；
4. 终点抬升 ：到达路径最后一个点后，末端垂直抬升回 SAFE_Z 安全高度。
执行完成后汇总输出：
路径总点数、碰撞点数、不可达点数
避障验证结论： [PASS] 全程无碰撞 或 [FAIL] 存在碰撞或不可达

```python
def execute_path(robot, grid_map, world_path: list, label: str,
                 cube_positions: list, half_extents: tuple,
                 client_id: int):
    """
    驱动机械臂末端沿路径点列表移动，含完整起降流程与碰撞检测。
    流程: 安全位 → 起点正上方(SAFE_Z) → 下降至(PATH_Z) → 沿路径运动 → 终点抬升(SAFE_Z)。
    """
    print("\n[路径执行] %s: 点数=%d, 高度=%.3f m" %
          (label, len(world_path), PATH_Z))

    sx, sy = world_path[0]
    gx, gy = world_path[-1]
    collision_count = 0
    unreachable_count = 0
    # 阶段1: 从待机位移至起点正上方(SAFE_Z)
    print("[%s] 阶段1: 移至起点正上方 (%.3f, %.3f, %.3f)" % (label, sx, sy, SAFE_Z))
    robot.move_one_point(sx, sy, SAFE_Z, log=True)
    # 阶段2: 垂直下降至执行高度(PATH_Z)
    print("[%s] 阶段2: 下降至执行高度 (%.3f, %.3f, %.3f)" % (label, sx, sy, PATH_Z))
    robot.move_one_point(sx, sy, PATH_Z, log=True)
    # 阶段3: 沿路径逐点运动
    print("[%s] 阶段3: 沿路径运动 (%d个点)" % (label, len(world_path)))
    for i, (wx, wy) in enumerate(world_path):
        if i % max(1, len(world_path) // 10) == 0:
            print("[%s] 第%d/%d点: (%.3f, %.3f)" %
                  (label, i + 1, len(world_path), wx, wy))
        if _check_collision_with_cubes(grid_map, wx, wy, cube_positions, half_extents):
            collision_count += 1
            print("[碰撞日志] %s 第%d点 (%.3f,%.3f) 与物块碰撞!" %
                  (label, i + 1, wx, wy))
        success, _ = robot.move_one_point(wx, wy, PATH_Z, log=False)
        if not success:
            unreachable_count += 1
            print("[碰撞日志] %s 第%d点 末端未达目标, 偏差超容差" % (label, i + 1))
    # 阶段4: 终点抬升至安全高度
    print("[%s] 阶段4: 终点抬升至安全高度 (%.3f, %.3f, %.3f)" % (label, gx, gy, SAFE_Z))
    robot.move_one_point(gx, gy, SAFE_Z, log=True)
    # 汇总
    pass_ok = (collision_count == 0 and unreachable_count == 0)
    print("[%s] 路径点数=%d, 碰撞=%d, 不可达=%d, 避障=%s" %
          (label, len(world_path), collision_count, unreachable_count,
           "PASS" if pass_ok else "FAIL"))
    return pass_ok
```

## 5.1 工作成果总结
本实验以 KUKA IIWA 七自由度机械臂为执行载体，基于 PyBullet 仿真平台，围绕"仿真环境搭建→TSP遍历路径优化→网格地图避障规划"三条主线，完整实现了机器人智能分拣系统的仿真验证，主要工作成果如下：
实验一：仿真环境构建与基础抓取。 基于 PyBullet 构建了包含地面、KIVA 货架、KUKA IIWA 机械臂和 5 个彩色物块的完整工业仿真场景；封装了 SimRobot 机械臂控制模块，实现了底层关节控制、笛卡尔空间平滑运动（线性插值+逆运动学）和预设位姿归位等接口；设计了"接近→下落→抬升"的标准化三段式抓取动作流水线；实现了轨迹数据记录与日志输出功能，末端定位误差均小于 0.005m，验证了运动控制的精度和一致性。
实验二：TSP分拣路径优化。 以物料抓取点为 TSP 节点，构建了带权完全图和邻接矩阵，独立实现了贪心算法、模拟退火算法和遗传算法三种 TSP 求解方案。实验结果表明，模拟退火和遗传算法均找到了最优路径 0→1→3→2→4（总长 1.0236m），比贪心算法的 1.1033m 缩短 7.2%，且模拟退火以仅 40ms 的计算耗时在效率和精度之间取得了最佳平衡。最优路径已成功对接机械臂抓取流水线，实现了按 TSP 最优序列驱动的完整闭环。
实验三：网格地图与避障路径规划。 将物料坐标降维为二维障碍物，以 0.01m 分辨率生成了二值网格地图；严格按伪代码实现了 A* 算法（OpenSet/CloseSet 双集合+四邻域扩展+欧氏启发）和 RRT 算法（目标偏向采样+线段碰撞检测）；在同一地图上以相同起终点完成了对比测试。A* 在路径质量（0.39m）和规划效率（5ms）上均优于 RRT（0.44m, 62ms），两种算法规划的路径均通过了碰撞验证，机械臂沿路径运动全程无碰撞。
## 5.2 存在问题与改进方向
尽管本实验完成了预期目标，但仍存在以下可改进之处：
TSP算法方面： 当前仅测试了 n=5 的节点规模，未验证算法在更大规模（如 n=10、n=20）下的性能表现和扩展性。模拟退火的降温系数和遗传算法的交叉变异率均采用固定值，未进行参数调优。后续可引入参数网格搜索或自适应参数调整策略。
路径规划方面： A* 采用四邻域扩展，路径由水平/垂直线段构成，转折生硬。若改为八邻域扩展并引入路径平滑后处理（如样条插值或梯度下降），可在保持无碰撞的前提下显著提升轨迹平滑性。RRT 的最近邻搜索采用暴力遍历 O(n)，当树节点数量增大时效率下降明显，可引入 KD-Tree 进行加速。
仿真真实度方面： 当前采用位置控制模式驱动关节，未模拟真实的动力学效应（如关节摩擦、电机响应延迟）。抓取动作仅模拟了"接近→下落→抬升"的运动轨迹，未涉及夹爪闭合、力反馈等真实抓取环节。后续可引入 PyBullet 的约束仿真和力/扭矩传感器来实现更真实的抓取交互。
视觉感知方面： 实验中物料坐标直接使用预设值，略过了视觉识别与坐标转换环节。虽然符合实验指导书的简化方案要求，但完整的视觉伺服闭环（机械臂拍照→图像采集→目标检测→坐标转换→路径规划）是智能分拣系统的关键环节，值得进一步实现。
