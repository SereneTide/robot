# 2.1 作业1：机械臂视觉控制仿真环境构建
## 一、代码需实现全部功能
### 1. 基础仿真环境搭建模块（基于`显示基本场景.py`扩展）
1. 初始化物理仿真客户端、全局重力`(0,0,-9.81)`、全局可视化相机视角；
2. 加载地面`plane.urdf`、自定义工作台、自定义工业场景（流水线/货架二选一）；
3. 批量生成分拣物料方块，支持自定义物料数量、尺寸、三维坐标；
4. 封装场景绘制函数：`draw_workspace()`，统一管理工作台、障碍物物料、货架支架。

### 2. SimRobot机械臂调用与运动控制模块
1. 实例化机械臂对象，实现基础姿态控制：
   - `go_to_rest()`：机械臂回到待机安全位；
   - `goto_joint_pose()`：输入六维关节弧度，控制各关节运动，增加到达容差判断，返回是否到达标识；
   - `go_to_point()`：输入三维笛卡尔坐标，运动至目标末端点位，返回逆解成功、无碰撞双标志；
2. 单点移动与抓取函数封装：
   - `move_one_point()`：机械臂末端平滑移动至单个空间坐标；
   - `pick_one_object()`：实现抓取物料完整动作流程。

### 3. RGBD视觉采集与坐标转换模块
1. 相机控制：机械臂移动至拍照位、固定相机外参，获取RGB图像、深度图、相机内参；
2. 坐标转换核心函数：
   - `trans_point_from_camera_to_base()`：相机坐标系三维点 → 机械臂基座坐标系世界坐标；
3. 可选拓展：自主编写`detect()`目标检测函数，从RGB+深度图识别物料中心；
   简化方案：跳过视觉检测，直接使用预设`cube_xyz_list`物料坐标作为检测输出。

### 4. 视觉伺服完整主流程（键盘交互触发）
1. 仿真循环持续刷新`p.stepSimulation()`；
2. 监听键盘Z键，按下后自动执行完整流水线：
   机械臂拍照位 → 采集图像 → 物料坐标提取 → 坐标转换 → 生成网格地图 → A*路径规划 → 逐点驱动机械臂沿路径运动；
3. 实时打印：当前末端坐标、规划路径点、仿真运行时长。

## 二、作业1代码开发硬性要求

# 2.2 作业2：智能算法求解分拣TSP最短遍历路径
## 一、代码需实现全部功能
### 1. TSP问题建模模块
1. 读取作业1仿真场景中所有物料抓取点坐标集合；
2. 计算任意两点间欧式距离，自动生成**邻接矩阵**；
3. 封装图结构绘制工具：打印邻接矩阵，支持输出可视化无向图文本信息；
4. 统一TSP基础父类`TSP`，提供公共接口：
   - `router_distance()`：输入路径序列，计算整条路径总长度；
   - `get_all_points()`：读取所有物料节点坐标。

### 2. 三种TSP优化算法独立实现
#### 算法1：贪心算法
1. 以指定起点出发；
2. 每一步遍历所有未访问节点，选择距离当前点最近节点；
3. 循环直至所有节点遍历完成，输出完整路径序列；
4. 统计总路径长度、算法运行耗时。

#### 算法2：模拟退火SA（基于指导书SASolution模板扩展）
1. 继承TSP父类，初始化随机初始遍历路径；
2. 邻域扰动：随机交换路径两个节点生成新解；
3. 能量差ΔE判断，以指数概率接受更差解；
4. 按降温系数持续降温，迭代至设定轮次后输出最优路径；
5. 输出最优总距离、运行时间。

#### 算法3：自选第三种TSP算法（蚁群/遗传算法二选一）
以遗传算法举例：种群初始化、交叉、变异、选择迭代寻优，输出最优遍历路径。

### 3. 算法对比与输出模块
1. 统一接口输入相同物料节点，分别运行三种算法；
2. 自动记录：总路径长度、程序运行耗时、路径节点顺序；
3. 控制台打印对比表格，保存数据用于实验报告分析；
4. 对接机械臂：将最优TSP遍历序列坐标依次传入`move_one_point()`，控制机械臂按最优顺序抓取物料。

## 二、作业2代码开发硬性要求
1. 基于作业1仿真场景数据建模，节点为分拣台全部物料抓取点；
2. 三种算法必须独立封装类/函数，代码结构清晰可单独调用；
3. 统一起点、统一节点数据集，保证对比公平；
4. 输出邻接矩阵文本、路径序列、量化对比数据；
5. 实现机械臂按TSP最优路径依次抓取物料的仿真演示。

# 2.3 作业3：网格地图+A*/RRT避障路径规划代码
## 一、代码需实现全部功能
### 1. 二维网格地图建模模块
1. 读取场景物料三维坐标，统一取工作台高度，降维为二维平面障碍物；
2. `Map_from_points`网格地图生成类：
   - 根据世界坐标、网格分辨率、障碍物点位生成二值网格地图；
   - 世界坐标 ↔ 网格UV坐标双向转换函数；
   - 标记障碍物网格，禁止通行；
3. 网格可视化输出：打印二维网格矩阵，区分通路/障碍物。

### 2. A*避障路径规划算法实现
1. 严格按照指导书伪代码实现：OpenSet、CloseSet双集合管理；
2. 启发函数采用曼哈顿距离/欧氏距离；
3. 遍历四邻域网格，跳过障碍物与已关闭节点；
4. 回溯父节点生成完整网格路径；
5. 转换函数：网格UV路径 → 机械臂世界三维坐标点列表。

### 3. RRT快速扩展随机树算法实现
1. 随机采样空间生成随机节点；
2. 寻找树上最近节点，生成扩展新节点；
3. 碰撞检测：新路径穿过障碍物则舍弃；
4. 迭代至终点区域后回溯生成完整避障路径；
5. 输出世界坐标系下连续路径点。

### 4. 路径与机械臂联动模块
1. 自定义规划起点、终点世界坐标；
2. 分别调用A*、RRT生成两条避障路径；
3. 循环遍历路径点列表，调用`robot.move_one_point()`驱动机械臂末端沿路径移动；
4. 全程碰撞检测，打印是否发生碰撞，验证避障效果。

## 二、作业3代码开发硬性要求
1. 所有分拣物料作为网格障碍物，不可通行；
2. 同时实现A*、RRT两套避障算法，同一地图、同起点终点对比；
3. 输出网格地图文本可视化、规划路径坐标点；
4. 仿真演示机械臂绕过障碍物从起点到达终点，无碰撞；
5. 代码增加碰撞日志输出，记录全程是否触发障碍物碰撞。
